# ماژول داشبورد و BI

این سند مستندات ماژول BI است: مرکز فرماندهی `/bi`، هشدارها (`/bi/alerts`) و گزارش‌ها/چاپ (`/bi/reports`).

> **ارجاع‌ها:** `PRD.md` §BI، `README.md`، کامنت‌های `Tarazin.Ui/Modules/Bi/` و اسکیل `tarazin-reporting`.

---

## ۱. مرور

- **مرکز فرماندهی** `/bi` — ۱۴ تب اجرایی/مالی/فروش/خزانه/طلا/ارز/انبار/مشتریان/بدهی‌ها/حقوق/فروشگاه/اهداف/هشدار/تحلیل هوشمند.
- **هشدارها:** صفحهٔ `/bi/alerts` — اسکریپت `bi.BiAlerts` از دادهٔ واقعی.
- **گزارش‌ها و چاپ:** صفحهٔ `/bi/reports` — کاتالوگ گزارش‌های BI از اسکریپت‌های نامدار + چاپ/PDF با **موتور چاپ عمومی (QuestPDF)**.

## ۲. معماری گزارش‌ها (`/bi/reports`)

- هر گزارش یک **تعریف کاتالوگ** است: `BiReportDefinition` (کلید، عنوان، زیرعنوان، اسکیما، اسکریپت، پارامترها، عنوان فارسی ستون‌ها) — فایل `Tarazin.Ui/Modules/Bi/BiReportDefinition.cs`.
- داده فقط از **اسکریپت‌های نامدار موجود** می‌آید (`DbService.QueryAsync`) — هیچ SQL در UI نیست.
- چاپ با `PrintGenericAsync` انجام می‌شود:
  1. داده از اسکریپت گزارش واکشی می‌شود (پارامترهای بازهٔ تاریخ nullable).
  2. یک قالب پویا (`PrintTemplateDef`) از ستون‌های تعریف گزارش ساخته می‌شود (اندازه A4، جهت بر اساس تعداد ستون، فونت ۸.۵pt، هدر شرکت).
  3. قالب + داده به `TemplatePrintDialog` (موتور چاپ عمومی) داده می‌شود — چاپ و PDF از **همان قالب** ساخته می‌شوند و همیشه یکسان‌اند.
- قالب هر گزارش در دیزاینر چاپ قابل طراحی است (`TemplateId = "bi.<key>"`).

## ۳. فونت

- فونت همهٔ چاپ‌ها **Vazirmatn** است — از TTF جاسازی‌شدهٔ `VazirmatnFontRegistrar` (QuestPDF)، نه CDN و نه فونت سیستمی. جزئیات و گارد در `tarazin-reporting/SKILL.md` §۳د.

## ۴. نکته‌ها

- هیچ موتور رندر/چاپ دیگری (مانند Viewer شخص ثالث) در پروژه وجود ندارد؛ اگر برای یک گزارش خروجی خاص نیاز شد، همان مسیر `PdfReportService`/قالب‌ها را گسترش بده (مطابق اسکیل `tarazin-reporting`).
