# ماژول ارز — مستندات فنی

## نمای کلی

ماژول ارز مدیریت جامع نرخ‌ها، کیف پول‌ها، خرید/فروش ارز، معاملات ترکیبی و تبدیل ارز را بر عهده دارد. این ماژول با حسابداری و خزانه‌داری یکپارچه است.

## اسکیمه

`currency` — تمام جداول و اسکریپت‌ها در این اسکیمه قرار دارند.

## جداول اصلی

| جدول | توضیح |
|---|---|
| `Currencies` | لیست ارزها (کد، نام، نماد) |
| `Wallets` | کیف پول هر ارز در هر شرکت |
| `PriceRates` | نرخ‌های ۷گانه: آنلاین/دستی/سیستم/خرید/فروش/حسابداری/میانی |
| `RateOverrides` | بازنویسی دستی نرخ برای تاریخ خاص |
| `FxTransactions` | معاملات ارزی (خرید/فروش) |
| `FxCombinedTransactions` | معاملات ترکیبی (طلا + ارز) |
| `AssetValuation` | ارزش لحظه‌ای دارایی ارزی |
| `PriceSources` | منابع قیمت آنلاین (TabloTala, Matisa) |
| `Settings` | تنظیمات ماژول (کارمزد، مالیات) |

## نرخ‌های ۷گانه

هر ارز در هر لحظه ۷ نرخ دارد:

| نرخ | کاربرد |
|---|---|
| `OnlineRate` | دریافت خودکار از API |
| `ManualRate` | تنظیم دستی توسط کاربر |
| `SystemRate` | نرخ پیش‌فرض سیستم |
| `BuyRate` | نرخ خرید |
| `SellRate` | نرخ فروش |
| `AccountingRate` | نرخ ثبت حسابداری |
| `MidRate` | میانگین خرید/فروش |

## کیف پول

هر شرکت برای هر ارز یک کیف پول دارد:
- **IRR (ریال)**: متصل به صندوق خزانه‌داری
- **USD/EUR/...**: کیف پول مستقل با موجودی و نرخ

## معاملات

### خرید/فروش ارز (FxTransactionCreate)
- ثبت خرید یا فروش ارز
- به‌روزرسانی خودکار کیف پول
- ثبت سند حسابداری (یاداشت)

### معامله ترکیبی (FxCombinedCreate)
- خرید/فروش هم‌زمان طلا و ارز
- تسویه نقدی + چک + نسیه

### تبدیل ارز (ConvertExecute)
- تبدیل یک ارز به ارز دیگر
- محاسبه خودکار بر اساس نرخ سیستم
- کارمزد قابل تنظیم

## دریافت آنلاین نرخ

از طریق `PriceSources`:
- **TabloTala**: قیمت طلا و ارز ایران
- **Matisa**: نرخ ارز جهانی
- به‌روزرسانی خودکار با `FeedApply.sql`

## ارزش لحظه‌ای و سود/زیان

- `AssetValuation.sql`: محاسبه ارزش کل دارایی ارزی
- `PnlSummary.sql`: خلاصه سود/زیان ارزی در بازهٔ تاریخی
- مقایسه نرخ خرید با نرخ فعلی

## یکپارچه‌سازی با سایر ماژول‌ها

| ماژول | ارتباط |
|---|---|
| حسابداری | سند حسابداری خودکار برای هر معامله |
| خزانه‌داری | کیف پول IRR متصل به صندوق |
| طلافروشی | نرخ ارز برای فاکتورهای ترکیبی طلا+ارز |
| BI | داشبورد ارزش دارایی و نمودار نرخ |

## API اسکریپت‌ها

```
currency/CurrencyList.sql          — لیست ارزها
currency/WalletList.sql            — کیف پول‌ها با موجودی
currency/RateBoard.sql             — تابلوی نرخ‌ها
currency/RateUpsert.sql            — ثبت/ویرایش نرخ
currency/RateOverride.sql          — بازنویسی دستی نرخ
currency/FxTransactionCreate.sql   — معامله ارزی
currency/FxCombinedCreate.sql      — معامله ترکیبی
currency/ConvertExecute.sql        — تبدیل ارز
currency/ConvertPreview.sql        — پیش‌نمایش تبدیل
currency/AssetValuation.sql        — ارزش لحظه‌ای
currency/PnlSummary.sql            — سود/زیان
currency/FeedApply.sql             — اعمال نرخ آنلاین
currency/PriceSourceList.sql       — منابع قیمت
currency/SettingsList.sql          — تنظیمات
```

## RLS و ایزولاسیون چندشرکتی

- تمام جداول دارای `CompanyId` هستند
- فیلتر RLS بر اساس شرکت فعال کاربر
